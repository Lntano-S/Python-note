# Chapter 3: 基本数据类型

## 3.1 数字类型

1. **int 类型**

| 进制种类 | 引导符号 |
| :--: | :--: |
| 二进制  |  0b  |
| 八进制  |  0o  |
| 十六进制 |  0x  |
> 十六进制中，用 A - F 代表 10 - 15


2. **float 类型**
	- 科学计数法：`<a>e<b>` = a * 10^b
	- 用 `round()` 函数来消除 float 运算带来的不确定尾数
```Python
	round(123.456789, 3) # 123.457
	round(0.1 + 0.2) # 0.300000000004
	round(0.1 + 0.2, 3) # 0.3
```

	 

3. **complex 类型**
	使用 `z.real` 和 `z.imag` 分别获取 complex 类型的 实部 和 虚部

4. **bool 类型 —— True 、 False**
	False -> 0
	True -> 1
	None -> 无 没有

5. **整数序列 —— `range()` 函数**
	`range(a, b, 步长)`  [a, b)

## 3.2 数字运算

1. **数字运算符**

|  运算符   | 描述  |
| :----: | :-: |
| x // y | 整除  |
| x % y  |  模  |
| x ** y | 乘方  |
> 对于模运算，`day%7` 表示星期，`n%2` 表示奇偶


2. **数字运算函数**

|        函数        | 描述                        |
| :--------------: | :------------------------ |
|     `abs()`      | 绝对值                       |
|  `divmod(x, y)`  | 商余，输出二元元组 (x // y, x % y) |
| `pow(x, y[, z])` | 模幂函数，表示 (x ** y) % z      |
|  `round(x, y)`   | 保留 x 的 y 位小数              |
|     `max()`      | 寻找最大值                     |
|     `min()`      | 寻找最小值                     |
